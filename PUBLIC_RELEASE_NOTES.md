# Public release notes

- Original project-oriented milestone structure, source code, tests, documentation, and Web source.
- An independently generated synthetic transaction CSV with a documented fixed seed.
- A fixed synthetic Web JSON contract and a dependency-free static dashboard demo.

## Deliberately excluded

- Internal requirement documents.

- Dependency directories, build directories, caches, and local environment files.

Empty artifact directories contain `.gitkeep` so the original delivery structure remains visible.
